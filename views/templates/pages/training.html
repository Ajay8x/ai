Data Train Hone Ke Baad Kahan Save Hota Hai? (Storage Topology Guide)

Jab bhi model train hota hai (via training/gpu_train.py ya training/train.py), sara processed dataset aur learned neural weights niche diye gaye specific locations par automatically persist ho jate hain:

  • 1. PyTorch Tensor Weights: models/ajax_neural_intent.pt (~374 KB) file me neural network ke 3-layer parameters (weights and biases) binary form me save hote hain.
  • 2. Vocabulary & Label Dictionary: models/vocab_metadata.json me sabhi 946 unique tokens aur 100 intent labels ka index save hota hai.
  • 3. Canonical Triggers: data/intents.json (~55 KB) me human-readable trigger patterns update hote hain.
  • 4. Continuous Learning Store: Chat ke doran user dwara approve kiye gaye live interaction samples MongoDB Atlas ke training_examples collection (ya fallback data/ajax.db SQLite) me hamesha ke liye save rehte hain.
  • 5. Runtime Execution: Server boot hote hi ai/neural/intent_classifier.py in dono files ko RAM me load kar leta hai taaki user queries bina kisi delay ke <0.05ms me classify ho sakein!
