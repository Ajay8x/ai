# AI Voice Assistant (Jarvis)

This is a Python-based personal AI voice assistant that can listen to your voice commands, open various websites, play YouTube videos, fetch Wikipedia summaries, and tell the current time and date.

## Requirements

Before running the script, make sure to install the required Python packages.

You can install all dependencies by running:
```bash
pip install -r requirements.txt
```

### Dependencies Included:
- **pyttsx3**: For text-to-speech conversion.
- **SpeechRecognition**: To recognize and process voice commands.
- **wikipedia**: To fetch data from Wikipedia.
- **pywhatkit**: For playing YouTube videos and other automations.
- **PyAudio**: Required by `SpeechRecognition` to use the microphone.

## Usage
Run the main Python file to start the assistant:
```bash
python main.py
```
